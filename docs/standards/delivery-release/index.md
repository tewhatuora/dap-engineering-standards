# Delivery Release Overview

## [Continuous Integration](continuous-integration.md)

_Build, test, and scan every change for security and quality issues before it merges._

## [Build & Artifact Management](build-artifact-management.md)

_Build once, and run that same artifact everywhere._

## [Continuous Delivery & Deployment](continuous-delivery-deployment.md)

_Make deployment routine, automated, and low-risk, not a rare, high-stakes event._

## [Progressive Delivery Strategies](progressive-delivery-strategies.md)

_Limit a new change to a small share of production traffic before it reaches everyone._

## [Feature Flagging](feature-flagging.md)

_Decouple deploying code from releasing it._

## [Release Strategy](release-strategy.md)

_A release is a deliberate decision, not a side effect of a pipeline finishing._

## [Rollback Strategy](rollback-strategy.md)

_Recovery from a failed deployment must be fast and rehearsed, not improvised under pressure._
