# AI Engineering Overview

## [Approved AI Tooling](approved-ai-tooling.md)

_Only vetted, organisation-provisioned AI tools may be used for engineering work._

## [Prompt Data Handling](prompt-data-handling.md)

_A prompt is a data disclosure; never include secrets, patient data, or more than a task needs._

## [AI-Assisted Development](ai-assisted-development.md)

_AI may write the code, but the submitting developer remains fully accountable for it._

## [AI Usage & Verification in Code Review](ai-usage-verification-in-code-review.md)

_Disclose AI involvement, and give it exactly the same scrutiny as any other change._

## [AI Cost Considerations & Optimisation](ai-cost-considerations-optimisation.md)

_Match context size, model choice, and session length to what the task actually needs._
