# Delivery and Release

## Overview

Delivery and release practices give changes a defined path to production while keeping built artifacts unchanged. They also keep release separate from deployment.

Choose a principle below to read its full reasoning.

## Principles

### [Immutable Artifacts](immutable-artifacts.md)

Built artifacts keep the same identity and content as they move through delivery environments.

### [Safe Delivery](safe-delivery.md)

Small, verified changes move to production through consistent checks, with recovery options ready and release managed separately from deployment.
